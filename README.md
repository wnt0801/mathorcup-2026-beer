## 当前结果与限制

- 化学数据250×234，感官数据250×53，编号一一对应。
- 候选化学输入231列，感官评分50项；输入列还需进一步核验。
- 化学数据73个缺失单元格，感官评分无缺失。
- 数据字典匹配50项，其中numeric 26项、categorical 24项；原始类型不能直接决定当前汇总数据的模型类型。
- 当前演示目标：A_malt_all。训练200款、测试50款，按风格分层，random_state=42。
- 测试集均值基准：MAE约0.562、RMSE约0.742、R²约-0.045。
- 当前笔记本尚不包含后续讨论的岭回归代码和结果。
- 感官数据使用变换后的尺度，尚未解决原始0—6分还原。不得将线性缩放称为真实还原。
